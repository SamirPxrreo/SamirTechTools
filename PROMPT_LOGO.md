# Prompt para generar logo de SamirTechTools

Copia uno de estos prompts en Midjourney, DALL·E, Leonardo, Ideogram o ChatGPT (con generación de imágenes).

---

### Prompt Principal (Recomendado - Minimal Pro)

```
Minimalist monogram logo for "SamirTechTools", letters "ST" intertwined, modern tech style, clean geometric shapes, rounded square icon with subtle gradient from slate-900 to indigo-600, white "ST" negative space, flat design, vector, ultra clean, premium IT tools brand, suitable for app icon and taskbar, no text, no shadows, 2 colors only -- style: flat vector, minimalist
```

**Versión en español (para IAs en español):**
```
Logo minimalista monograma para "SamirTechTools", letras "ST" entrelazadas, estilo tech moderno, formas geométricas limpias, icono cuadrado redondeado (20px radius) con degradado sutil de slate-900 a indigo-600, letras "ST" en blanco en negativo, diseño plano vectorial, ultra limpio, marca premium de herramientas informáticas, apto para icono de app y barra de tareas, sin texto extra, sin sombras, solo 2 colores
```


---

### Configuración recomendada

- **Formato:** `1024x1024`, `PNG` con fondo transparente y fondo sólido
- **Colores exactos:** `Slate-900 #0f172a`, `Indigo-600 #4f46e5`, `Blanco #ffffff`
- **Estilo:** Flat, vector, sin degradados fuertes, sin 3D
- **Uso:** Icono de `public/icon.png` (512x512) y `electron` builder. Reemplaza `public/icon.png` y reconstruye con `npm run electron:build`

### Prompt negativo (para evitar errores)
```
no photorealistic, no 3d, no shadows, no gradients harsh, no text "SamirTechTools" inside icon (solo monograma ST), no busy details
```

### Para generar solo el isotipo cuadrado redondeado (ideal para taskbar)
```
App icon, rounded square 20px radius, slate-900 background, white "ST" monogram centered, bold geometric sans, 2px inner subtle border, ultra minimal, iOS/macOS app icon style, vector
```
